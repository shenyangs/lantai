# GEO 评分卡

## 指标

| 指标 | 计算 | 注意 |
|---|---|---|
| 提及覆盖率 | 提及品牌的有效答案数 / 有效答案总数 | 区分品牌直查与非品牌提示 |
| 推荐可见份额 | 推荐列表中品牌出现次数 / 全部品牌出现次数 | 同一答案重复出现只计一次 |
| 事实准确率 | 正确事实项 / 可核对事实项 | 无法核对的不计入分母 |
| 引用覆盖率 | 含可访问来源的答案数 / 有效答案总数 | 平台不提供引用时单列 |
| 高质量引用率 | 权威且直接支持答案的引用 / 全部引用 | 聚合转载不能替代原始来源 |
| 来源就绪度 | 已覆盖关键问题的权威页面数 / 关键问题数 | 页面需可抓取、更新日期清楚 |

## 证据行

每条样本至少记录：

- `captured_at`
- `platform`
- `prompt_id`
- `prompt`
- `brand_mentioned`
- `position_or_role`
- `sentiment`
- `claims`
- `citations`
- `errors`
- `notes`

## 解释

- 样本少于 30 条时优先展示原始计数，不用小数点制造精度。
- 平台、语言、地区和时间窗口不同，不直接合并成一个总分。
- 评分用于发现来源和事实问题，不代表模型或平台背书。
