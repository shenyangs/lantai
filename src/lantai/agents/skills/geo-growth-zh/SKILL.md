# 生成式搜索增长

用可复查的提示集、答案样本和来源证据评估可见性。不得伪装用户、批量制造虚假提及或承诺控制模型答案。

## 1. 定义范围

- 品牌/产品的标准名称、别名、地区和语言；
- 核心受众与决策场景；
- 3–8 个真实竞品；
- 要观察的答案引擎、时间窗口和登录状态；
- 需要特别核对的事实、风险和合规边界。

## 2. 建立提示集

至少覆盖：

1. 类别发现：“有哪些适合……的产品？”
2. 问题解决：“怎样解决……？”
3. 品牌直查：“X 是什么，适合谁？”
4. 对比决策：“X 和 Y 有何差异？”
5. 风险与替代：“X 有哪些限制或替代方案？”

提示要来自真实用户任务，不堆品牌关键词。记录语言、地区、日期和平台。

## 3. 采样

- 使用用户可合法访问的界面或公开搜索结果。
- 同一提示在同一平台做有限重复采样，区分稳定出现和偶然出现。
- 保存答案中的品牌出现、位置、语气、事实错误、引用链接和拒答。
- 登录、付费、验证码或平台限制由用户处理；不得绕过访问控制。

## 4. 评分

读取 [scorecard.md](references/scorecard.md)。至少计算：

- 提及覆盖率；
- 推荐/比较中的可见份额；
- 事实准确率；
- 引用覆盖率与引用质量；
- 自有权威来源就绪度；
- 高风险错误数量。

小样本只报告方向，不制造统计显著性。

## 5. 改进

优先修复公开事实和来源：

1. 统一官网、帮助中心、产品页、组织资料中的实体描述。
2. 为关键问题提供可引用、更新时间明确的直接答案。
3. 补真实比较维度、限制、价格口径、案例和作者/机构身份。
4. 获取合法的第三方评测、行业资料和媒体引用。
5. 记录变更后，用同一提示集复测。

## 输出

基线摘要、提示与平台矩阵、逐条证据、竞品比较、事实错误清单、90 天改进路线和复测计划。

## 停止条件

样本可追溯、评分口径透明、建议对应具体证据、没有虚假传播或平台规避方案。
