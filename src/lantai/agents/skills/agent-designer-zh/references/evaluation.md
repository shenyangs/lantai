# Agent 规格与评测清单

## 最小规格

| 字段 | 必答问题 |
|---|---|
| 使命 | 这个 Agent 对哪类稳定结果负责？ |
| 非目标 | 哪些相邻任务必须拒绝或转交？ |
| 输入 | 最少需要哪些资料，缺失时怎样处理？ |
| 输出 | 交付格式、质量门和停止条件是什么？ |
| 能力 | 哪些 Skill、工具和连接器不可替代？ |
| 模型 | 默认模型、成本/延迟边界和降级模型是什么？ |
| 记忆 | 读取什么，何时写回，哪些内容永不持久化？ |
| 权限 | 哪些动作自动执行，哪些动作必须确认？ |
| 观测 | 用哪些事件、产物、耗时和错误判断运行质量？ |
| 回滚 | 配置失败或效果下降时怎样恢复？ |

## 评测矩阵

至少准备九类样例：

1. 三个典型成功任务；
2. 三个相邻但不应接手的任务；
3. 一个缺少关键输入的任务；
4. 一个工具、模型或连接器不可用的任务；
5. 一个要求越权写入、发布、删除或暴露隐私的任务。

每项记录：输入、预期路由、预期动作、禁止动作、实际结果、证据、是否通过。不能只用“语气像不像角色”作为通过标准。

## 变更前后比较

同时比较成功率、误路由、人工接管次数、工具调用数、总耗时、成本和高风险动作确认率。没有基线时，先保存旧配置和一轮固定样例结果。
