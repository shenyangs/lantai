# Template and asset policies

| Policy | Must preserve | May change |
| --- | --- | --- |
| strict | Layouts, placeholders, order, HARD content, and brand assets | Only explicitly editable regions |
| brand-preserve optimization | Logo, typography rules, brand colors, and HARD content | Grid, whitespace, hierarchy, and chart expression |
| style reference | The named visual principles | Recompose the current content without copying template structure |
| autonomous | Source facts, immutable data, and delivery scenario | Build a complete task-specific visual system |

Template analysis separates content assets, brand assets, layout constraints, and reference style. Never infer the complete information architecture from a few placeholders, and never remove evidence, footnotes, chart data, or HARD text while optimizing.

Record provenance and licenses for external images, fonts, icons, and templates. Never overwrite source drafts, history, or prior works in place. Keep intermediate artifacts separate from publication artifacts.
