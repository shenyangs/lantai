# Visual direction

Choose the semantic relationship and visual protagonist before laying out a slide. Comparison, trend, cause, process, hierarchy, matrix, and data narrative need distinct graphic grammar; they must not all collapse into text cards.

Every `visual_direction` covers concept, audience density, palette, type hierarchy, grid, image language, chart language, shape language, and recurring motif. It is a deck-wide constraint, not a command to repeat one template on every slide.

Titles, key numbers, chart data, tables, annotations, and sources remain native editable objects. Rasterize only complex illustration, photography, or texture that does not need structural editing. A full-slide screenshot is not a substitute for native office objects.

Maintain both slide hierarchy and deck rhythm. Cover, transition, judgment, evidence, decision, and closing slides must not all be isomorphic. Review every slide, then review narrative, repetition, rhythm, and transitions across the complete deck.
