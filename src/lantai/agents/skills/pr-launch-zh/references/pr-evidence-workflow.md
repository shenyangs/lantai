# 证据驱动的 PR 工作流

## 风险分级

| 级别 | 特征 | 默认动作 |
|---|---|---|
| L0 例行 | 事实稳定、影响有限、无明显争议 | 正常发布与监测 |
| L1 关注 | 存在误读、局部投诉或信息缺口 | 补事实、准备 Q&A、加强监测 |
| L2 重大 | 多平台扩散、核心利益相关者受影响 | 统一口径、负责人确认、持续更新 |
| L3 危机 | 人身安全、违法、重大损失或监管介入 | 立即升级人工与法务，不自动发布 |

## 主张台账

每条对外主张记录：

- 主张文本；
- 证据和来源定位；
- 事实负责人；
- 可公开状态；
- 时间有效期；
- 可能反例；
- 审批状态。

## 声明结构

1. 已确认发生了什么。
2. 对受影响方意味着什么。
3. 当前已采取什么行动。
4. 哪些仍在调查，何时更新。
5. 用户或媒体可以在哪里获得帮助。

避免把道歉、责任、承诺和法律判断混成一句话。

## Q&A

- 从最难问题开始，不用内部项目顺序。
- 回答区分已知、未知和暂不能公开。
- 不重复未经证实的有害指控；必要时概括问题。
- 每个答案标记可公开范围和更新负责人。

## 监测

记录原始来源、传播链、影响人群、核心误解和实质问题。热度、情绪和业务影响分别观察；不要用声量替代影响。
