# Web 视觉系统

## 先做内容层级

1. 用一句话确定页面主要任务。
2. 只保留一个最强主行动，次要行动降低视觉权重。
3. 按“结论—证据—细节—行动”组织复杂页面。

## 视觉约束

- 建立 4–8px 间距体系，不用随机 margin 修补布局。
- 正文字号和行高保证连续阅读；展示字只用于少量关键位置。
- 颜色首先表达状态与层级，不用多种高饱和色制造热闹。
- 卡片、圆角、阴影和渐变各有用途；没有用途就删掉。
- 图标优先使用项目现有图标库，不混入 emoji 或临时 SVG。

## 响应式与可访问性

- 至少检查 360px、768px 和主要桌面宽度。
- 键盘可达，焦点可见，表单有 label，图像有合理替代文本。
- 动效尊重 `prefers-reduced-motion`，不阻断操作。
- 对比度、点击热区、文本截断和长内容状态必须实测。

## 从截图还原

- 先量布局比例、网格、边距、字号和色值，再实现。
- 不把截图中的偶然内容当成通用组件规则。
- 对无法确认的细节做最小假设，并在交付说明中列出。
