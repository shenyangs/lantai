# 常见产品模式

先按任务和信息密度选模式，再定视觉。不要把这些模式当成模板拼贴。

| 产品类型 | 首要任务 | 推荐结构 | 视觉重点 | 避免 |
|---|---|---|---|---|
| SaaS 落地页 | 解释价值并转化 | Hero、证据、能力、案例、价格/行动 | 强主张、真实产品画面 | 空洞渐变、虚构客户 Logo |
| 管理后台 | 快速判断与操作 | 全局导航、摘要、筛选、主表/图、详情 | 密度、状态、稳定对齐 | 每块都做卡片、隐藏单位 |
| 数据报告 | 理解结论与证据 | 摘要、指标、趋势、分解、限制 | 数字口径、注释、可打印 | 图表装饰化、截断坐标轴 |
| 知识库/文档 | 查找与连续阅读 | 搜索、树状导航、正文、目录 | 可扫读、代码与表格 | 正文过宽、层级不清 |
| 电商详情 | 建立信任并购买 | 媒体、价格、选择、权益、评价 | 商品信息、库存和错误态 | 假倒计时、隐藏费用 |
| 金融工具 | 理解风险与变化 | 总览、持仓/指标、趋势、事件、风险 | 数字格式、涨跌语义、审慎 | 只用红绿色、弱化风险 |
| 医疗/健康 | 安全完成任务 | 任务入口、个人状态、说明、升级渠道 | 可读性、隐私、紧急边界 | 诊断式承诺、低对比度 |
| 创作者作品集 | 展示判断和作品 | 定位、精选案例、过程、关于、联系 | 图像节奏、项目叙事 | 过量动效、作品同权 |
| 活动/报名页 | 解释并完成报名 | 价值、时间地点、议程、嘉宾、报名 | 时间信息、行动连续性 | 关键条件藏在页脚 |
| 移动效率工具 | 高频快速完成 | 单一主任务、列表/画布、轻设置 | 触控热区、手势反馈 | 桌面页面缩小版 |
| 设置与权限 | 安全改变状态 | 分组、当前值、影响说明、确认 | 可逆性、危险区、保存反馈 | 模糊开关、静默自动保存 |
| 导入/迁移向导 | 降低不确定性 | 来源、范围、预览、冲突、进度、结果 | 可撤销、错误定位、数据边界 | 一键黑盒导入 |

## 选择检查

- 主要任务是否在首屏可理解？
- 关键状态是否通过文字和结构表达，而不是只靠颜色？
- 高风险动作是否远离日常操作并说明后果？
- 内容、数据和控件密度是否匹配实际使用频率？
