# 图片表格核对表

## 结构

- 表格边界没有包含页眉、页脚、图片说明或重复分页表头。
- 多级表头已展开为稳定列名；合并单元格的继承规则已说明。
- 每行字段数量一致，空白单元格与不存在的单元格没有混为一谈。

## 字符

- 重点区分 `0/O`、`1/I/l`、`5/S`、`8/B`、小数点与千位分隔符。
- 数字、负号、百分号、币种、单位和脚注符号已逐项检查。
- 名称、编号和代码不做自动纠错；不确定内容保留候选值。

## 复算

- 对存在合计、小计、均值或百分比的表格进行复算。
- 随机抽查首行、末行和至少三行中间数据。
- 跨页表格检查上一页末行与下一页首行是否重复或缺失。

## 交付

- CSV 使用 UTF-8；需要保留格式、公式或多表时使用 XLSX。
- 文件名不覆盖原图或用户已有文件。
- 最终回复列出低可信单元格及其定位。
