# Agent 运行诊断分类表

| 层 | 常见证据 | 典型反证 | 最小验证 |
|---|---|---|---|
| 输入/路由 | 任务被错误角色或 Skill 接收，必要输入缺失 | 同输入在固定角色稳定成功 | 固定 Agent 与输入重跑只读样例 |
| 上下文/记忆 | 关键资料未装入、旧记忆覆盖新指令、截断 | 模型请求中已含正确资料 | 比较上下文包与来源文件 |
| 模型 | 超时、限流、空响应、格式漂移 | 工具前已出现错误决定 | 用相同 fixture 比较一次模型调用 |
| Skill | 未触发、冲突触发、指令断链 | 运行中已读取正确 Skill 且遵循 | 检查描述冲突与资源链接 |
| 工具/MCP | 连接失败、schema 不匹配、重复同参调用 | 工具返回成功且内容满足合同 | 单独 probe 并列工具 schema |
| 权限/审批 | 等待确认、权限拒绝、凭证过期 | 没有审批事件且凭证状态正常 | 读取生命周期状态，不回显凭证 |
| 编排/状态机 | 终态缺失、取消竞态、重复 attempt | 各 attempt 边界和终态完整 | 按 run/attempt 重建事件序列 |
| 存储/网络 | 保存失败、断连、恢复后状态漂移 | 同时段健康检查正常 | 最小读写或网络健康检查 |
| 界面呈现 | 后端已完成但 UI 仍显示运行中 | 后端也没有终态 | 对比 API 状态与界面时间戳 |

## 置信度

- 高：直接证据完整、可稳定复现、主要替代解释已排除。
- 中：多项间接证据一致，但缺少关键事件或稳定复现。
- 低：只有症状相似或单条日志，需更多证据。

## 安全要求

运行证据中的 token、Cookie、Authorization、密码、API key 和个人内容必须脱敏。日志或事件可能包含用户输入时，只引用诊断所需的最小片段。
