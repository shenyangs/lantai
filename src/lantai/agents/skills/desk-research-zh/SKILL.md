# 案头研究

先形成证据，再形成判断。研究不是搜索结果拼接，也不是为了凑完整而填补空白。

## 选择模式

读取 [research-modes.md](references/research-modes.md)，选择最小充分模式：

- 快速案头研究；
- 深度研究；
- 学术写作取证；
- 用户研究决策室；
- 编辑选题；
- 跨学科角度拓展。

不要同时跑所有模式。

## 选择证据源

用户提到“我的资料、知识库、历史沉淀、导入文档、Wiki”或问题明显依赖内部背景时，先走本地 Wiki：

1. 用 `wiki_ingest_status` 确认摄取队列和近期状态；仍在处理时说明证据可能不完整。
2. 用 `wiki_search` 以核心术语、别名和反例分批检索，保存结果中的 page/source 路径和匹配信息。
3. 用 `wiki_read` 阅读支撑关键主张的页面或原始来源，不把搜索摘要当全文证据。
4. 需要理解项目、人物或概念关系时，用 `wiki_graph_neighbors` 查看一至三层邻居，再回到原文核实。
5. 本地 Wiki 无结果或不足时，先标记本地证据缺口；仅在任务允许公开网络补充时再使用观澜或 Web。

本地资料与公开网页分开登记来源。引用本地证据时保留页面/原始来源路径和检索时间，不输出无关个人信息、内部运行文件或大段原文。Wiki 工具只读；不要声称已写回知识库。

## 工作流

1. **界定问题**：写出决策问题、时间范围、地区、术语、排除项和停止条件。
2. **拆查询**：覆盖支持证据、反例、原始来源、近期变化和未知项。
3. **检索**：按上面的证据源路由；中文互联网优先使用 `guanlan_research`、`guanlan_search`、`guanlan_read`，补充使用澜台 Web 工具。
4. **登记来源**：记录标题、发布者、日期、URL、来源类型、支持的具体主张和限制。
5. **交叉核验**：高影响事实尽量使用两个独立来源，其中至少一个接近原始材料。
6. **综合**：分开输出事实、来源观点、分析推断和未知项。
7. **反证**：主动寻找会推翻当前结论的材料，不把搜索饱和当成事实确定。
8. **交付**：先给结论与置信度，再给证据台账、分歧、限制和下一步。

## 来源规则

- 时间敏感事实必须带检索时间。
- 论文、法规、财报、公告和产品文档优先引用原文。
- 搜索摘要只用于发现线索，不能单独支撑关键结论。
- 本地 Wiki 搜索结果同样只用于发现线索，关键结论应回读页面或原始来源。
- 不伪造 DOI、作者、页码、数字或引语；无法取得全文时明确说明只核对到摘要。
- 用户研究中的个体陈述不能自动外推为总体规律。

## 权限与隐私

默认只读公开来源。用户明确要求基于其 Wiki/导入资料研究可视为本任务的只读授权，但不扩展到其他工作区、账号或受限系统。登录、付费墙、个人账号和其他内部资料需要单独授权；不得绕过访问控制。研究材料含个人信息时做最小化引用和去标识化。

## 停止条件

核心问题均有证据或明确标记未知、关键来源可访问、分歧已呈现、结论可以追溯到证据台账。
