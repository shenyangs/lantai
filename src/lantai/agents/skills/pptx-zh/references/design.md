# 视觉方向

先用语义决定页面的关系类型和视觉主角，再设计布局。比较、趋势、因果、过程、层级、矩阵和数据叙事应使用不同的图形语法，不得都退化为文字卡片。

每套作品的 `visual_direction` 至少包含设计概念、受众密度、配色、字体层级、网格、图像语言、图表语言、形状语言和 recurring motif。视觉方向是全局约束，不是每页套同一模板。

标题、关键数字、图表数据、表格、注释和来源应保留为原生可编辑对象。只有复杂插图、摄影、纹理等不需要结构编辑的视觉才转为图像。不得以整页截图代替原生办公对象。

必须同时维持页内层级与全套节奏：封面、转场、判断、证据、决策和收束页不能全部同构。所有页都要检查，整套另审叙事、重复、节奏和转场。
