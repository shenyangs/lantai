# 模板与资产政策

| 政策 | 必须保留 | 允许改变 |
| --- | --- | --- |
| strict | 版式、占位符、顺序、HARD 内容、品牌资产 | 仅允许明确可编辑范围 |
| 品牌保留优化 | logo、字体规范、品牌色、HARD 内容 | 栅格、留白、信息层级与图表表达 |
| style reference | 被指定的视觉原则 | 不复制模板结构，按当前内容重新编排 |
| 无模板自主 | 来源事实、不可改数据、交付场景 | 建立完整且特定于任务的视觉系统 |

模板解析要区分内容资产、品牌资产、版式约束和参考样式。不得从几个占位符推导全套信息架构，也不得在优化时删除证据、脚注、图表数据或 HARD 文字。

外部图像、字体、图标和模板必须记录来源与许可。用户原稿、历史版本和作品不得被原地覆盖；中间产物与发布产物必须分开。
