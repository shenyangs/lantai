# 内容编辑契约

1. 先建立材料覆盖表：来源、主张、支撑证据、必留事实、不可改数据、不确定性、所属页。DOC 转换与 DOCX 正文、图表、注释是不同证据边界，未读取的部分必须披露。
2. 每页只有一个可辩护的 `key_message`，并使用 `source_refs` 和 `immutable_facts` 追溯。标题应陈述判断，不只是主题名。
3. 原始表格、台账或会议记录先编辑为差异、变化、取舍和后果。默认保留表格的关系，禁止按行复制成“来源 A / 来源 B / 融合裁决”等重复卡片。
4. 数据页要说清单位、时间范围、口径和算法。没有证据的原因、趋势外推、用户心理和商业结论不得写入。
5. 删减时先删重复表达，不删关键事实、反证、风险、约束和不确定性。长原文可移入 speaker notes，但必须保留来源身份。
6. 在故事板阶段先检查覆盖与逻辑，再做美术。美术不得用来隐藏事实缺口。
