# 图形选择与输出检查

## 选择

| 任务 | 首选 | 避免 |
| --- | --- | --- |
| 时间变化 | 折线图 | 无序分类折线 |
| 分类比较 | 条形图 | 3D 柱、装饰性面积 |
| 少量部分占整体 | 饼图 | 超过约 6 个扇区 |
| 两个数值变量关系 | 散点图 | 用聚合柱代替观察点 |
| 多指标轮廓 | 雷达图 | 不同单位未经标准化 |

若重点是精确查值而非关系，保留表格；可以在图表正文前给出关键数值，但不要重复完整数据。

## 数据检查

1. 数值是否来自已读到的源数据，而非模型估计。
2. 总量、占比和分母能否互相校验。
3. 日期是否统一时区和粒度。
4. 缺失值是零、未知还是不适用。
5. 聚合是否会掩盖样本量或极端值。
6. 颜色是否承载了真实维度；单系列不需要人为着色。

## 协议检查

- 围栏语言必须是小写 `echarts`。
- 围栏内部是一个 JSON 对象，不含注释和尾随逗号。
- `height` 有效范围为 240–720，缺省为 360。
- `option` 不含 JavaScript 函数或外部资源。
- 只使用宿主列出的图表类型和组件。
- 完成输出后不要再附第二个相互冲突的图表配置。
