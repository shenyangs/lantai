# 浏览器测试计划

## 用例字段

- ID
- 前置条件
- 入口
- 操作步骤
- 预期结果
- 数据影响
- 优先级
- 证据要求

## 最小 smoke

1. 页面能加载，主标题或核心区域可见。
2. 主行动可执行，并进入正确成功或下一步状态。
3. 空态、错误态和加载态至少检查一项。
4. 控制台没有与改动相关的新错误。
5. 360px 左右窄屏没有水平溢出或不可操作控件。
6. 刷新或返回后状态符合产品预期。

## 安全

- 不在生产环境创建大量测试数据。
- 不自动提交支付、发布、删除、邀请或发送消息。
- 不把登录 Cookie、Token 或个人信息写入截图说明和日志。
- 需要真实外部变更时，执行前再次确认准确目标。
