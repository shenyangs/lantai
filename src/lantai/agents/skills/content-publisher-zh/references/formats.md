# 内容交付类型

## 长文 / 杂志文章

- 适合观点、访谈、案例和叙事内容。
- 使用醒目标题、导语、章节、引语和少量边注。
- 正文宽度优先保证阅读，不用满屏卡片化。

## 数据报告

- 适合 KPI、调研、复盘和结构化分析。
- 顺序为执行摘要、关键指标、图表/表格、发现、限制、建议。
- 数字必须带单位、时间范围、口径和来源。

## 单页简历

- 优先姓名与定位、经历、成果、技能、教育和联系方式。
- 一页内容不足时允许留白，不用无意义装饰填满。
- 打印到 A4 时不得裁切核心内容。

## 竖版海报 / 分享图

- 只承载一个主要信息和一个明确行动。
- 先设计 9:16 或用户指定尺寸，再适配预览。
- 文本较多时改用文章或报告，不把正文硬塞进海报。

## 通用阅读页

- 用于材料汇编、说明文档和轻量发布。
- 提供目录、搜索友好的语义标题和清晰来源区。
