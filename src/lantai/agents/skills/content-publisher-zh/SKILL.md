# 内容发布工作室

将内容转换与视觉编排分开处理。先保证材料、结构和事实正确，再生成自包含、可打开、可打印的交付页面。

## 1. 获取内容

- Markdown、纯文本：直接读取。
- DOCX/PPTX/XLSX/PDF：交给对应 Office/PDF Skill 提取，保留标题、表格、脚注和来源边界。
- 网页：使用澜台网络读取能力；保留原链接和访问时间。
- 图片：只在用户授权下读取；不得自动上传到第三方服务。

缺少转换器时使用澜台已有读取和 Open XML 能力，不在运行时安装 Pandoc、MarkItDown 或其他工具。

## 2. 选择交付类型

读取 [formats.md](references/formats.md)，从以下类型中选择一个：

- 长文/杂志文章；
- 数据报告；
- 单页简历；
- 竖版海报或分享图；
- 通用阅读页。

不要为了展示模板而扭曲内容。数据密集时优先报告，叙事密集时优先文章。

## 3. 建立内容模型

1. 提取标题、摘要、章节、引语、数据、图注、来源和行动。
2. 删除重复导航、页眉页脚和转换噪声。
3. 明确哪些内容是原文、编辑改写、推断和待核信息。
4. 长内容生成目录；表格在窄屏允许横向滚动。

## 4. 生成

- 默认生成一个自包含 HTML，CSS 与必要 JS 内联。
- 优先使用系统字体；没有必要不加载远程字体、统计脚本或 CDN。
- 对用户提供的图片使用相对路径或经授权的嵌入方式，不复制未知许可资产。
- HTML 做语义化标题、可打印样式、键盘焦点和合理对比度。
- 需要 PDF 时先浏览器验收 HTML，再通过用户环境现有能力导出。

## 5. 验收

1. 用浏览器打开实际文件。
2. 检查桌面与窄屏、目录跳转、链接、长表格、图片缺失和打印分页。
3. 检查标题、数字、引用和来源没有被视觉处理改写。
4. 保存必要截图并修复明显溢出。

## 停止条件

内容来源清楚、页面可离线打开、关键链接有效、窄屏和打印无阻断问题、没有未说明的远程依赖。
