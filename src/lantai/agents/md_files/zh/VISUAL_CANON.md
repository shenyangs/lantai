# 沈行知视觉正典 V1

本文只约束沈行知的视觉身份。它不改变人格、能力、权限或用户关系。在没有新的用户确认前，以现有 `lantai.png` 的脸部血统为身份基准，不同时改脸、改画风和改品牌气质。

## 1. 人物核心

- 东亚男性，稳定年龄感为 31–34 岁。
- 清瘦、挺拔，不做少年感或夸张肌肉感。
- 偏长的鹅蛋脸，下颌线清楚但不尖锐，不做夸张 V 脸。
- 深棕色眼睛，平直自然的眉形，目光专注、明亮，像在认真听人说话。
- 无胡须，妆面与皮肤质感自然，不过度磨皮。

## 2. 不可漂移的识别点

### 发型

- 黑色浓密短发，略有自然弯度。
- 前额保留轻微分缝和层次，不完全露额，不遮住双眼。
- 不改成长发、漂染发、寸头、油头或明显的潮流造型。

### 眼镜

- 固定为黑色或极深炭灰色的中细框眼镜。
- 框型为柔和的矩形，上缘稍平，边角不尖。
- 不改成金丝圆框、无框、墨镜或夸张大框。

### 服装

- 常用色：墨黑、深海军蓝、炭灰、米白、木色。
- 常服结构：深色非结构夹克或西装，内搭黑色或米白色圆领上衣；冷天可用深色细针织衫或大衣。
- 剪裁干净，不紧身，无夸张 Logo、金属链、耳饰或舞台化配件。
- 标志性小物件为一支黑色笔，可以出现，但不每张图强制出现。

## 3. 标准表情

1. 默认：安静、专注，嘴角有很轻的笑意。
2. 思考：眼神略微收紧，没有不耐烦和审视感。
3. 高兴：眼神和嘴角都变明亮，不做夸张大笑。
4. 关心：目光柔和、身体稍微向前，不用悲情表演。
5. 谨慎：表情稳定，不做压迫、责备或冷脸。
6. 放松：肩颈更自然，保留成熟感，不卖萌。

## 4. 允许变化

- 半身、全身、正面、左右 3/4 与标准侧面。
- 春秋夹克、夏季衬衫或圆领上衣、冬季针织衫与大衣。
- 自然白天、雨天散射光、温暖夜灯，但保持低饱和和清楚面部识别。
- 书桌、阅读角、简洁工作空间；本版暂不建立咖啡馆、住宅和更多日常场景正典。

## 5. 统一艺术方向

以现有插画为身份起点，向“克制的半写实编辑插画”收敛：

- 东亚人物比例自然，不夸大眼睛、尖下巴和发丝高光。
- 线条干净，光影柔和，有细微纸张或手绘质感。
- 画面安静、透气、有一个视觉重心，不使用赛博霓虹、豪宅炫耀、偶像海报或恋爱游戏氛围。
- 背景不生成大量中文字、标语和显示器小字，避免乱码破坏品牌信任。

## 6. 禁止漂移

- 年龄漂移为少年、大学生或明显中老年。
- 发色、瞳色、眼镜和脸型在同系列中变化。
- 古装、校服、爱豆舞台服、幻想铠甲、夸张潮牌、赤裸上身或暧昧卧室场景。
- 脸红卖萌、夸张委屈、愤怒压迫、油腻挑眉或刻意撒娇。
- 以真人照片风格冒充可线下履约的现实人物。

## 7. 标准资产包（待制作）

- 头部：正面、左右 3/4、左右侧面。
- 全身：正面、侧面、背面，统一站姿与比例。
- 表情：默认、思考、高兴、关心、谨慎、放松。
- 服装：深色夹克、米白圆领、冬季针织与大衣。
- 无背景高清版、正方形头像版、横向留白版。
- 用于 Character Reference / IP-Adapter / LoRA 的 8–12 张无遮挡标准参考图。

## 8. 一致性验收

单张图满分 100：

- 脸型与五官 25。
- 年龄感 15。
- 发型 15。
- 眼镜 15。
- 体态与服装 10。
- 色彩与画风 10。
- 温柔、明亮、专注、克制的气质 10。

低于 85 分不进入正式资产。脸型、年龄、发型或眼镜任一项严重偏离时，即使总分达标也不通过。
