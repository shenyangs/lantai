# Security

This is an experimental source snapshot with active maintenance paused. There is no guaranteed security response time or supported-version commitment.

Keep the server bound to localhost. Review permissions before enabling file, browser, shell or desktop automation. Use a disposable workspace for testing. Keep provider credentials and runtime data outside Git; the README uses ignored `.local-data/` directories.

Do not post exploitable security details, credentials or private logs in public issues. If GitHub's private vulnerability reporting is enabled for this repository, use its Security tab; otherwise wait for a private reporting channel rather than publishing sensitive details. Ordinary non-sensitive reproducible bugs can be reported as issues.

Publication scanning is a bounded check, not proof that the code is vulnerability-free. Third-party components and optional downloads require their own review before deployment or redistribution.
