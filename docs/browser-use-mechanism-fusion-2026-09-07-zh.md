# Browser Use 机制融合与底座判断

## 决策与来源

用户要求融合 browser-use 的代码机制；若新底座经证据确认明显优于现有能力，允许替换。当前决策是增强现有浏览器执行闭环。已找到可以通过局部改造修复的真实断点，尚无同模型、同站点的端到端对照数据证明必须替换整套底座。

参考仓库：https://github.com/shenyangs/browser-use

评估提交：`e25ab65e699af3031a1f2d348526de2844be0e89`，包版本 `0.13.10`。

参考实现：`browser_use/dom/service.py`、`browser_use/dom/serializer/serializer.py`、`browser_use/agent/views.py` 中的 `ActionLoopDetector`、`browser_use/agent/service.py`。

## 实际融合

1. **语义页面与执行目标分离。** 原先规划器只接受带 CSS selector 的元素，BrowserSkill 的原生引用不可执行，Playwright 的 `snapshot` 正文也未进入页面状态。新增有边界的语义快照适配，保留运行时实际返回的引用，并在当前页面状态内绑定，不生成猜测 selector。
2. **可见目标优先。** 在模型观察层先过滤隐藏元素再使用元素数量预算；保留 frame/shadow 范围、原生 tab id 和截断状态。该改动不能恢复浏览器采集端已经丢弃的节点；Electron 的采集上限和跨域框架仍是独立限制。
3. **动作成功与页面进展分离。** 新增不受元素引用编号变化影响的页面进展哈希，页面 revision 仍随引用改变以维持新鲜度边界。
4. **有事实依据的恢复。** 从既有任务历史计算动作重复、页面停滞和短周期往返，把事实交给模型判断下一步。连续翻页获得新内容不会仅因操作相同而停止；重复动作持续无页面进展时，使用现有无进展预算结束，保留证据。
5. **模型兼容。** 真实配置模型拒绝固定 `temperature=0`。浏览器规划与目标验收改为沿用客户端配置，避免浏览器子流程覆盖模型约束。
6. **真实结构化契约。** 原先只要求模型返回 `BrowserNextDecision`，没有提供字段 schema；真实模型连续两次生成了无法执行的结构。现在随系统指令提供由 Pydantic 契约生成的 JSON Schema，避免代码校验与提示词脱节。

新增模块只消费现有 `BrowserAgentContext`、`BrowserPageState`、`BrowserAgentHistoryItem`。无第二任务数据库、模型 SDK、浏览器守护进程或新 UI；执行继续经过 Broker 的域名、权限、单次确认和 effect 证据机制。

## 验证与证据界限

行为锁初次在原实现上得到 **6 个失败**：两种原生快照、隐藏元素挤占预算、引用编号假进展、原生标签及截断状态丢失、成功空转不能停止。另加温度契约行为锁，原实现失败。

回归还覆盖：重复引用拒绝、正文中的伪引用、Playwright ref 清单校验、隐藏/禁用目标拒绝、持续有效翻页、往返循环事实、温度契约。

2026-09-07 验证：相关 Python 回归 **211 passed**，新增模块静态检查和基础体验门禁通过。真实模型消费合成页面完成完整规划与验收链，执行序列为 `click → snapshot`，最终准确交付 `8.4/10` 与页面影评摘要；共 4 次模型调用、5315 tokens。计费字段返回 0，不据此推断服务免费。该检查未操作真实网站，`real_site_verified=false`。

复现命令：`python scripts/browser_agent_fusion_smoke.py --live-model`。它仅发送合成电影页面和任务给当前配置模型；显式标记用于提示有真实模型调用费用。网站端到端、已登录浏览器和打包态结果不包含在此证据中。

这组结果证明明确的协议和控制缺陷得到修复，不是“网页任务成功率超过 browser-use”的证明。上游 README 的云端成绩、专用模型和反检测环境不能替代澜台本机环境的实测结果。

## 整体替换的后续判据

在相同模型、任务、站点、登录身份和预算下，比较澜台基线、当前融合版本、上游开源 Agent。至少保留真实站点任务结果、失败归因、费用、耗时、接管次数和最终产物证据。云端产品另记成本与数据流，不混入开源库成绩。

只有局部增强仍无法弥补的完成率/稳定性差距被反复证实，且停止、确认、工作区、产物和打包契约不退化，才以版本化迁移替换浏览器执行底座。当前不满足整体替换前提。
